# Swift-era reference stills

The twelve PNGs here are the documentation stills produced by the archived
Swift demo, taken from the `swift-oracle` tag before `docs/images` was removed
from the repository history (I13, 2026-11-20). They are kept out of the README
because they no longer match the shipped renderer; they are kept at all so the
Swift-era framing and colour can still be compared against the Rust captures.

Each file keeps its original name. The Swift-era hero GIF is not included: the
Rust recording replaced it and the old one is recoverable from the
`strange-attractor-screensaver-backup-*.bundle` taken before the rewrite.

The Rust captures that are current live in `docs/images` and are regenerated by
`docs/capture_all.sh`.
