# Запланированные аттракторы и пополнение каталога

Каталог расширяется через `attractors.json` без изменения кода (все формулы из полиномов/sin/cos/tan/abs уже поддерживаются парсером `Expression.supportedFunctions`).

## Добавлено 2026-10-01 (+15, каталог 5 → 20)
`lu`, `chua`, `sprott_a`…`sprott_j`, `halvorsen`, `rabinovich_fabrikant`, `moore_spiegel`. Параметрические диапазоны подобраны так, чтобы система оставалась численно устойчивой (проверка RK4 на углах диапазона + стартах). Подробности формул — в `mem:domain_model`.

## В очереди (формулы требуют верификации по первоисточнику)
- **Аттрактор Дадраса (Dadras & Momeni 2009).** Трёхмерный, полиномиальный — наверняка реализуем без доработки ядра, но точную систему не удалось подтвердить (доступ к сети в среде ограничен: `www.sprott.physics.wisc.edu` DNS-fail, DuckDuckGo CAPTCHA, MathWorld 404). Внести после подтверждения формул и устойчивого диапазона параметров.
- **Sprott K–S.** Полный набор A–S у Спротта (Sprott 1994, «Some simple chaotic flows»). A–J добавлены (запомнены точно), K–S требуют сверки с первоисточником. У Спротта среди K–S есть системы с кубическими нелинейностями (x³/y³) и членами вида x²·y — парсер их поддержит.

## Правила
- Новый аттрактор обязан пройти существующий автотест «Every bundled catalog attractor stays finite under its debug defaults» (шаг RK4 2000, дефолты = midpoints). Если не проходит — сначала подобрать рабочий диапазон параметров (численно, на углах диапазона), потом менять конфиг.
- Найденные подводные камни (вики-наборы, которые расходятся): R–F a=1.1/g=0.87; Moore–Spiegel вики-форма `-z-x-Ry+Tx-x³`. Использовать рабочие каноны из `mem:domain_model`.
