# Доменная модель и глоссарий: strange-attractor-screensaver

## Бизнес-сущности

### Аттрактор (Attractor)
Множество точек (траектория), к которому стремится детерминированная динамическая система. В проекте — описывается системой ОДУ и визуализируется.
- **Аттрактор Лоренца:** `x'=a(y-x)`, `y'=x(r-z)-y`, `z'=xy-bz` (классика: r=28).
- **Аттрактор Рёсслера:** `x'=-y-z`, `y'=x+ay`, `z'=b+z(x-c)` (a,b,c>0).
- **Аттрактор Томаса:** `x'=sin(y)-bx`, `y'=sin(z)-by`, `z'=sin(x)-bz` (обычно b=0.2081).
- Расширяется через конфиг-файл без изменения кода.

### Descriptor (AttractorDescriptor)
Мета-описание аттрактора в `attractors.json`: id, имя, формулы, параметры, гиперпараметры. Загружается через Codable.

### Параметр (Parameter)
Коэффициент системы (a, b, c, r...) с диапазоном `[min, max]`. При запуске выбирается случайно из диапазона.

### Гиперпараметры симуляции (SimulationHyperparameters)
Настройки визуализации/симуляции (не физика системы): скорость симуляции, длина шага (точность интегрирования), скорость вращения камеры, скорость изменения цвета следа, длина следа, и т.п. Выбираются случайно из диапазонов; для отладки задаются вручную.

### Состояние (State)
Текущий вектор (x, y, z) точки на траектории.

### Симуляция / Аттрактор-движок (AttractorEngine)
Поток, который шагает динамическую систему численным интегрированием (RK4/Euler) и выдаёт последовательность точек.

### Траектория / След (Trace)
Буфер последних точек, отображаемый рендером как линия/облако с цветовой градацией.

### Файл конфигурации (attractors.json)
Файл, описывающий аттракторы выражениями (формулы), диапазоны параметров и диапазоны гиперпараметров.

## Глоссарий
- **ОДУ / дифференциальная формула** — система обыкновенных дифференциальных уравнений, задающая динамику аттрактора.
- **NSExpression** — Apple-парсер арифметических выражений, используемый для разбора строк формул.
- **Численное интегрирование** — приближённое решение ОДУ (метод RK4, метод Эйлера).
- **.appex** — пакет app-extension (современный формат скринсейвера).
- **ScreenSaverView** — главный класс скринсейвера (в новом формате `.appex`).
- **SceneKit / SCNView** — фреймворк и view для 3D-рендеринга.
- **Randomizer** — случайный выбор аттрактора, параметров и гиперпараметров при запуске.
- **DebugConfig** — ручной ввод параметров для отладки.

## Связи
- Один **Descriptor** → конкретный **AttractorModel** (состояние + параметры + формулы).
- **AttractorEngine** использует **ODESolver** для перехода между состояниями.
- **Randomizer/DebugConfig** → задают **параметры** и **гиперпараметры**.
- **TraceRenderer** читает буфер **Trace** из движка и отображает его в **SCNView**.
